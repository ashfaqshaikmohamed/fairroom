# Web demo recording script

Use the README quick start at http://localhost:3000 with DEMO_MODE=true. This is a web demonstration, not a recording of live phone delivery. Do not record secrets, private data or invitation URLs.

1. **0–15 seconds:** Landing page → Meet FairRoom. “Finding a home is a group decision.”
2. **15–35 seconds:** Show Alex, Sam and Jordan. Complete Sam’s saved preferences. “Everyone has their own budget and must-haves.”
3. **35–55 seconds:** Homes → Courtyard sample → Review split. “The engine checks the group’s requirements and calculates room-dependent shares.” The baseline total is $3,840; the sample room facts are illustrative.
4. **55–75 seconds:** Conversation → `split C1`, `like C1`, `saved`. Show the generated response and saved home.
5. **75–90 seconds:** Before you commit → Preview sample review. Keep its label visible. “We also show missing facts and questions to ask before deciding.”

Core matching and rent arithmetic execute; fixture data and the optional sample review are labeled. Do not claim this sequence uses live Factory, Chalk or Photon calls. See DEMO-AND-SPONSOR-TALKING-POINTS.md. Any real phone recording needs separate configuration and receipt verification. No final video file is generated by this guide.

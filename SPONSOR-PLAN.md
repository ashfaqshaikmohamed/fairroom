# Submission scope

Digital Trust is the proposed track fit: private budget limits, explicit constraints, exact totals, versioned proposals and visible missing evidence. Confirm current eligibility and category combinations with the organizers; this repository does not establish prize eligibility.

The default submission is a keyless web demo. Optional integrations are implemented but require actual service use before claiming sponsor requirements are met:

- Photon: hosted messaging adapter and roster checks. Local Mac transport is separate and does not prove hosted Photon group support.
- Chalk: optional Model Gateway intent classification and a local live-request evaluation runner. Mock tests are not hosted evaluation results.
- Factory: runtime listing-evidence review through read/check/submit tools. The prepared sample review is not a live SDK result. Using a coding tool during development alone is not the runtime integration.

No Daytona, Nessie, space-data, Telegram or voice integration is claimed. Do not add them for this submission-readiness pass. See FACTORY-CHALK-SETUP.md for optional setup and HANDOFF.md for current scope. No submission or purchase has been performed by this audit.
